DVR Intelbras não abre no navegador? Acesse pelo Acesso Web no Windows 10 e 11

Programa gratuito e de código aberto que permite usar o plugin ActiveX webrec dos DVRs Intelbras antigos, agora que o Internet Explorer não existe mais no Windows.

Baixar grátis Ver no GitHub

Este programa resolve se…

  • você digita o IP do DVR, faz login e nada acontece;
  • as câmeras não aparecem na página do DVR;
  • a página pede um plugin que não instala (webrec.cab);
  • o modo Internet Explorer do Edge também não funciona;
  • aparece o erro ocx.SetParams is not a function.

Como usar

  1. Baixe o .zip e extraia numa pasta.
  2. Clique com o botão direito em instalar-plugin.bat → Executar como administrador e informe o IP do DVR (ex.: 192.168.1.108).
  3. Abra o DvrViewer.exe, digite o endereço do DVR e clique em Ir.
  4. Faça login. As câmeras aparecem.

Por que os navegadores atuais não funcionam

Os DVRs Intelbras mais antigos exibem o vídeo com o controle ActiveX webrec.ocx, que o próprio aparelho fornece no arquivo webrec.cab. Chrome, Firefox e Edge não executam ActiveX. O modo IE do Edge se apresenta como IE11, mas a página do DVR só ativa o plugin para “MSIE” (IE10 ou anterior). Além disso, o plugin não é assinado digitalmente, então nem o IE o instala sozinho.

O DvrViewer é um navegador mínimo com o motor do Internet Explorer em modo IE10, que libera o ActiveX somente para o endereço do DVR. O instalador baixa o plugin do seu próprio DVR e o registra no Windows. Nenhum arquivo da Intelbras é redistribuído.

Segurança

Use o DvrViewer apenas para acessar o DVR na sua rede local. O motor do Internet Explorer é antigo e não deve ser usado para navegar na internet.
